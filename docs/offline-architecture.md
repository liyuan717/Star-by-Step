# ENERGY WORLD 1.1 离线架构

2026-11-08：用户明确修改规格，完全离线要求覆盖旧Supabase/在线账户/服务器写入要求。历史`supabase/`、旧联调测试与报告仅保留迁移参考，不参与手机运行和当前CI。

## 唯一数据源

手机私有目录的`energy-world-offline.db`是唯一业务数据源。Expo SQLite在应用启动时打开数据库，WAL模式、FULL同步、版本化schema。任务、目标、完成快照、钱包、永久XP、兑换快照、库存、建筑、成就、时间线、图片内容与操作回执分别保存在SQLite表中；不是在线数据缓存。图片原始内容以base64存于SQLite，展示用本地data URI，不依赖相册原文件、网络签名地址或缓存目录。

每张表的JSON行受JSON有效性约束；SQLite唯一索引约束任务周期、单笔完成/兑换流水、流水序号、装饰归属、装备槽、主线目标和时间线事件。完整行结构、关联引用、数值范围、流水、成长和图片引用还由`src/local/validate.ts`检查。

`LocalEngine`串行化本进程所有数据访问，`BEGIN IMMEDIATE`取得SQLite写锁。一次任务完成/奖励兑换在同一事务中写入快照、钱包、永久XP、流水、成长、成就、时间线和UUID回执。任一步失败回滚；进程中断由SQLite恢复未提交事务。UUID重复返回原结果，UUID绑定不同payload被拒绝。同周期不同UUID仍受任务周期唯一约束保护。奖励余额不足不会扣款。

操作意图先单独持久化到`pending_operations`。若进程在提交结果与界面确认之间被杀，下次启动可恢复同一UUID；回执和经济变更在同一事务提交，恢复不会重复记账。已明确回滚的失败会清理意图。没有任何网络请求重试队列。

页面查询来自本机SQLite。React Query使用`networkMode: always`，飞行模式不会暂停本地查询。没有Auth会话、邮箱、密码、登录、找回密码或远程服务调用。首次启动设置昵称和固定IANA时区后直接建世界。

## 保留规则

- ENERGY奖励整数1–300；每天最多100次、3000 ENERGY；永久XP与累计任务奖励一致；数值上限9万亿。
- once/daily/weekly周期，固定时区零点和周一计算；开始/结束日期、版本、暂停/归档、关联目标状态均校验；完成快照不随编辑改写。
- 奖励价格确认、余额检查、消费不减少XP；装饰只购一次，按槽装备；目标手动完成不额外发奖。
- 等级阈值与15档建筑AND条件沿用原规则；5项成就、7/30天统计、最长/当前连续天数、时间线全部本地计算。
- 离线版使用手机时间，不能像可信服务器一样防止用户任意修改系统时间。保留历史周期去重和每日限额；设备时间明显倒退时拒绝写入并提示校准。卸载后不承诺防篡改或恢复无备份的数据。

## 完整备份

单一`.energyworld.json`文件，包含格式标识、schema版本、备份UUID、时间、SHA-256校验和、全部业务表、UUID回执及图片内容。校验和用于识别文件损坏，并非防止文件所有者重新制作备份的数字签名。

导入依次检查文件大小、JSON格式、版本、校验和、每一行字段、同一世界归属、记录唯一性、引用完整性、每条流水的连续余额、累计收支、XP、等级、建筑、成就和图片内容hash。图片每张最多2MB、总计32MB，备份最多96MB、总记录最多50000条；超过限制明确拒绝，不截断导出。

界面先展示待恢复世界、余额、XP、目标/任务/图片数量，再由用户选择整体覆盖，并再次确认。唯一恢复模式是**替换**；不提供合并或追加资产。再次导入相同备份仍是同一份余额，不会叠加积分。旧备份会回退进度，确认页明确提示。

图片和业务行在同一SQLite事务替换，没有“数据库成功但图片尚未复制”的窗口。恢复失败保留原世界。待确认意图不从旧备份重放；恢复时清除本机旧意图，已完成UUID回执随完整数据恢复。

Android通过系统目录选择器导出到用户指定的App外部文件夹，并回读校验；卸载App不应删除该外部文件。导入通过系统文件选择器。iOS通过分享面板保存（本轮未在iOS运行）。Android关闭系统自动备份，App也没有云上传或自动同步；用户自行管理备份。卸载、清除应用数据前必须导出备份。

## 旧版一次性迁移

旧在线数据仍在旧服务中，升级不会删除它。旧版手机没有完整业务SQLite，因此不能凭旧SecureStore登录令牌离线还原远程世界。首次离线启动不会假称已迁移旧数据。

本次只读盘点：旧服务profiles/tasks/rewards/wallets均为0。此前临时测试账号已清理，没有需要迁移的现有世界。旧APK保存在`outputs/legacy/energy-world-online-1.0.apk`，不覆盖旧服务。

若之后发现自己的旧世界：在旧服务仍能访问的一次性迁移环境中执行：

```powershell
node --import tsx scripts/migrate-legacy.ts --user-id 旧用户UUID --output outputs/旧世界.energyworld.json
```

迁移工具仅在电脑上运行，读取本地CLI管理员凭据（不进入App），分页读取该用户13张业务表和全部引用图片，建立稳定本地图片标识、流水顺序，完成同一套全量校验后生成离线完整备份。缺少图片、对账失败或已有同名输出文件时中止。工具不修改或删除旧服务数据。随后把文件复制到手机，在首次引导或设置里确认导入；迁移完成后日常使用完全离线。当前脚本限定localhost，远程旧环境需要明确提供相应导出文件或另行扩展迁移工具，不能把云管理员密钥填入手机。
